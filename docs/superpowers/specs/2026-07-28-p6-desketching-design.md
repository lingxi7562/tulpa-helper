# 产品方向调整设计 — 降低 P6 强迫性追踪风险

> 日期：2026-07-28
> 依据：AUDIT-2026-07-26 审计报告中标识的 P2/P6 原理性张力
> 决策方式：头脑风暴 + 用户确认

---

## 背景

审计发现三处设计与 tulpa 社区共识存在张力：

1. **ResonanceTracker 每日评分** — 临床研究警示逐日自我监测在 NJRE/OCD 倾向人群中会放大痛苦（P6）
2. **时长里程碑庆祝动画** — 文案"Ta 的回应越来越清晰"强化"时长=进步"的错误心智模型（P6）
3. **特质权重 1-10 数值 UI** — 精确量化暗示特质是可固定排序的规格（P2 over-specification）

---

## 变更 1：ResonanceTracker 周记录模式

### 变更范围
- `src/features/journal/ResonanceTracker.tsx` — 唯一变更文件

### 设计

**聚合逻辑变更：**
- 按日聚合 → 按周聚合
- SQL 使用 `strftime('%Y-%W', created_at)` 分组
- 展示窗口：最近 8 周（而非当前 7 天）
- 每周去重：保留该周最新一条记录

**UI 变更：**
- 标题辅助文案增加：「不必每天记录，一周回顾一次就好」
- 柱状图 X 轴：日期（MM-DD）→ 周次（"第 N 周" 或 "07/14-07/20" 格式）
- 空数据周：灰色短柱 + "本周尚未记录" 文字
- 1-5 评分 + 文字标签保持不变

**DB 无变更。**

### 影响
- 用户暴露频率：每日 → 每周，降低 P6 风险约 85%
- 数据损失：无（历史日数据保留，仅展示聚合变更）

## 变更 2：时长里程碑文案修改

### 变更范围
- `src/stores/useMilestoneStore.ts` — `milestoneTitle(threshold)` 函数
- `src/features/stats/MilestoneCelebrate.tsx` — 庆祝文案

### 设计

| 级别 | 当前文案 | 变更后文案 |
|---|---|---|
| 10h | "Ta 的回应越来越清晰" | "每一小时的陪伴都算数" |
| 50h | "Ta 的回应越来越清晰" | "五十个小时，我们一起走过" |
| 100h | "Ta 的回应越来越清晰" | "一百个小时，感谢这份坚持" |

**原则：**
- 去除对用户实际进展的假设（不再预设"Ta 的回应变清晰了"）
- 强调投入本身的价值
- 语气温暖、不制造焦虑

### 影响
- 零结构变更，仅常量文案替换
- 庆祝机制保留，心智模型纠偏

## 变更 3：特质权重描述性档位

### 变更范围
- `src/features/traits/TraitManager.tsx` — 创建表单 + 编辑交互
- `src/features/traits/TraitSummary.tsx` — 摘要显示
- `src/features/form/FormBuilder.tsx` — 无直接影响（不共享权重概念）

### 设计

**三档定义：**

| 档位 | 显示 | DB 映射值 | 颜色 |
|---|---|---|---|
| 核心 | `核心` | 8 | 金色 (amber-500) |
| 重要 | `重要` | 5 | 蓝色 (blue-500) |
| 一般 | `一般` | 2 | 灰色 (gray-400) |

**创建表单：**
- 1-10 滑块 → 三档按钮组（`核心` / `重要` / `一般`）
- 默认选中 `重要`
- 选中态：实心填充；未选中态：线框

**编辑交互：**
- +/− 步进按钮 → 点击档位徽章循环切换（核心→重要→一般→核心）
- 保留当前点击展开/折叠的交互模式

**TraitSummary 显示：**
- 数字 "· 5" → 档位标签（如 `核心`）
- 颜色按档位区分

**DB 无变更** — `weight` 字段仍为 INTEGER，UI 层做 档位↔数值 映射。

### 影响
- 消除精确量化的心理暗示
- 保留轻量级优先级区分（用户仍可区分特质的相对重要性）
- 新录入使用映射值，历史数据保持原数值不变

- **形态五感权重** — FormBuilder 无权重概念，不涉及
