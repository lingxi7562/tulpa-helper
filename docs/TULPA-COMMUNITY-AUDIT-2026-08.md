## 本轮对照结果

- 已把 `Active Forcing`、`Narration`、`Imposition`、`Possession` 等主要界面词改为“专注陪伴、日常叙述、感官临场、身体协作”等中性词；数据库 `EntryType` 和旧标签保持兼容。
- 已加入本地“实践视角”偏好，并让 JSON 备份兼容旧文件；偏好不会解锁、锁定或改变任何能力。
- 视角切换与身体协作现在要求一次性的练习前确认：安全环境、可停止、接受部分/混合体验，不追求黑屏或失忆；切换时长改为可选。
- 10/50/100 小时不再默认弹出庆祝；统计仍可查看，时间标记须在统计页主动开启，手动里程碑不受影响。
- 已有的关系罗盘、回应迹象、自治观察、grounding 与错误重试继续保留；它们记录体验而不替用户判定来源。
- 共振记录按周保留并以“很淡/轻微/中等/明显/强烈”显示；数据库内部数值只用于兼容历史数据，不在 UI 中作为评分展示。
- 感官临场继续用 1–4 作为旧数据存储值，但界面改为“存在感/片段/维持/多感官”描述，并把备份校验范围收紧到 1–4。

## 明确不做

- 不把 tulpa、plurality、DID、精神病性体验或灵性解释互相等同。
- 不声称应用能创造独立意识、治疗疾病、证明超自然现象或保证任何练习结果。
- 不强制每日打分、累计小时、wonderland、visualization、switching、imposition 或身体协作。
- 不新增网络同步或 AI/LLM；数据继续本地优先，备份由用户主动导出。
