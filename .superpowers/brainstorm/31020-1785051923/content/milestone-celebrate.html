动画风格

A：纯 CSS 粒子

用 30-40 个绝对定位的彩色圆点，keyframes 随机方向飘落 + 旋转 + 淡出。零依赖，约 60 行 CSS。

效果：简洁、克制，与温暖品牌调性一致。类似 SimpleConfetti。

B：canvas-confetti 库

引入 canvas-confetti (~3KB gzip)，真实物理粒子效果（重力、旋转、拖尾），社区成熟方案。

效果：更华丽的彩带/纸屑爆炸，类似 GitHub 成就、Vercel 部署成功。
